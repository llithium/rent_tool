# API Reference

The app ships five serverless `GET` endpoints under `/api/*` ([src/routes/api/](../src/routes/api/)).
They exist to reach live data past browser CORS and to keep third-party keys server-side.

**Conventions**

- All endpoints are `GET` and return JSON.
- Bad/missing **required** params return **HTTP 400** (`{ "message": "…" }`). Every other
  failure — upstream down, not found, no key — returns **HTTP 200** with an `ok: false`
  (or empty-result) body, so the client can degrade gracefully instead of throwing.
- FIPS params are strings: `state` is 2 digits, `county` is 3 digits.
- Responses set `Cache-Control` for CDN/edge caching (durations noted per endpoint).

Typical call order for an off-list city:
`city-suggest` → (pick gives coords) → `geocode` (coords → FIPS) → `fmr` (and/or `acs`).
Seed cities skip this and use `/api/rents` + the bundled snapshot.

## GET `/api/city-suggest`

City autocomplete, proxied over [Photon](https://photon.komoot.io) (keyless OSM typeahead).
Filtered to US cities/towns/villages; each result carries coordinates so a pick can populate
the map without a second geocode call.

**Query params**

| Param | Required | Description |
| --- | --- | --- |
| `q` | yes | Search text. Fewer than 2 chars returns an empty list. |

**Response** `200`

```json
{
  "suggestions": [
    { "label": "Tampa, FL", "city": "Tampa", "state": "FL", "lat": 27.9477, "lng": -82.4584 }
  ]
}
```

Up to 8 de-duplicated suggestions. Any upstream failure returns `{ "suggestions": [] }`.
Cache: `max-age=60, s-maxage=300`.

**Example**

```bash
curl "http://localhost:5173/api/city-suggest?q=tampa"
```

## GET `/api/rents`

Fetches Zumper's National Rent Report, parses the top-100 table server-side, and caches it
in-memory for 6h (persists across warm invocations). Best-effort: if the page can't be
parsed it returns `rows: []` and the client keeps its bundled snapshot.

**Query params** — none.

**Response** `200`

```json
{
  "rows": [
    { "name": "New York, NY", "r1": 4200, "yoy": 3.1, "r2": 4600 }
  ],
  "reportDate": "May 1, 2026",
  "live": true,
  "cached": false
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `rows[].name` | string | `"City, ST"` |
| `rows[].r1` / `r2` | number | Median 1BR / 2BR rent (USD/mo) |
| `rows[].yoy` | number | 1BR year-over-year change (%) |
| `reportDate` | string \| null | Report date parsed from the page |
| `live` | boolean | `true` if any rows parsed |
| `cached` | boolean | Served from the in-memory cache |

Cache: `s-maxage=21600` (6h).

## GET `/api/geocode`

Resolves county/state FIPS from coordinates via the [FCC Area API](https://geo.fcc.gov/api/census/area)
(keyless). The FMR/ACS endpoints need FIPS; the client already has coords from the autocomplete pick.

**Query params**

| Param | Required | Description |
| --- | --- | --- |
| `lat` | yes | Latitude |
| `lng` | yes | Longitude |

Missing/invalid `lat`/`lng` → **400**.

**Response** `200`

```json
{
  "ok": true,
  "stateFips": "12",
  "countyFips": "057",
  "combinedFips": "12057",
  "county": "Hillsborough County",
  "state": "FL"
}
```

On any upstream failure: `{ "ok": false }`. Cache: `max-age=86400, s-maxage=604800`.

**Example**

```bash
curl "http://localhost:5173/api/geocode?lat=27.9477&lng=-82.4584"
```

## GET `/api/fmr`

HUD Fair Market Rents (40th-percentile) for a county. Uses the **live HUD API when
`HUD_TOKEN` is set**, otherwise (or on any failure) falls back to the bundled county table
([src/lib/data/fmr-county.json](../src/lib/data/fmr-county.json), generated by
[scripts/build-fmr-data.py](../scripts/build-fmr-data.py)) — so every US county resolves with
zero keys. New England counties with multiple town rows are averaged.

**Query params**

| Param | Required | Description |
| --- | --- | --- |
| `state` | yes | 2-digit state FIPS |
| `county` | yes | 3-digit county FIPS |

Malformed FIPS → **400**.

**Response** `200`

```json
{ "ok": true, "r1": 1696, "r2": 1977, "county": "", "year": "FY2026", "bundled": true }
```

| Field | Meaning |
| --- | --- |
| `r1` / `r2` | 1BR / 2BR Fair Market Rent (USD/mo) |
| `county` | County name (empty when served from the bundle) |
| `year` | Fiscal year of the figures |
| `bundled` | `true` = bundled table, `false` = live HUD API |

County not found in the bundle: `{ "ok": false, "reason": "not-found" }`.
Cache: `max-age=86400, s-maxage=2592000` (30d).

**Example**

```bash
curl "http://localhost:5173/api/fmr?state=12&county=057"
```

## GET `/api/acs`

Census ACS 5-year (2023) median gross rent by bedroom for a county. Used as a secondary
fallback. **Requires `CENSUS_KEY`** — the Census API now rejects keyless requests, so without
a key this short-circuits to `ok: false`.

Uses variables `B25031_003E` (1BR) and `B25031_004E` (2BR).

**Query params**

| Param | Required | Description |
| --- | --- | --- |
| `state` | yes | 2-digit state FIPS |
| `county` | yes | 3-digit county FIPS |

Malformed FIPS → **400**.

**Response** `200`

```json
{ "ok": true, "r1": 1350, "r2": 1580, "name": "Hillsborough County, Florida", "year": "2023" }
```

`r1`/`r2` are `null` when the Census returns no value. No key configured:
`{ "ok": false, "reason": "no-key" }`. Cache: `max-age=86400, s-maxage=2592000` (30d).

**Example**

```bash
curl "http://localhost:5173/api/acs?state=12&county=057"   # needs CENSUS_KEY set
```

## Environment variables

Both optional (see [.env.example](../.env.example)); set them in Vercel project settings for
production.

| Var | Enables | Get one |
| --- | --- | --- |
| `HUD_TOKEN` | Live HUD FMR figures (else bundled FY2026 table) | https://www.huduser.gov/portal/dataset/fmr-api.html |
| `CENSUS_KEY` | The ACS median-rent fallback | https://api.census.gov/data/key_signup.html |
